# Manipulation check: planned method

**Status: protocol draft; no results yet.** This document describes an intended independent check of generated conversation content. Complete and freeze the coding rules before recording outcomes.

## Unit and data

- Unit: individual conversation session.
- Primary source: actual generated utterances from the agent(s) targeted by each manipulation (normally Agent B), not the evaluator-generated `reason`.
- Planned sample: all 30 sessions per condition where feasible (29 or 30 usable score records does not determine whether the underlying conversation log exists).
- Baseline is coded using the same criteria as the relevant High/Low pair.

## Factors and proposed observable characteristics

| Factor | Evidence to assess |
|---|---|
| contentOfRemarks | Constructive suggestions/positive framing versus critical or negative remarks |
| politeness | Honorific/polite forms, cushioning/softening expressions, directness |
| informationSharing | Specific factual information, reasons, background explanations |
| support | Encouragement, practical help, assistance and alternative suggestions |
| communicationStyle | Empathy/recognition versus neutral task-only responses |
| leader'sApproach | Respect for autonomy and participative guidance versus directives/orders |
| emoji moderate | Actual emoji count, preferably per targeted utterance |
| a and b and c | Three distinct participants and configured/observed turn count |
| casual conversation | Social/relational topics and actual absence/presence of research-task problem solving |

## Recommended recording and reporting

Define a clear coding rubric (e.g., binary presence for an explicitly defined behavior, plus count or degree as appropriate). For each session record condition, session identifier, examined speaker/utterance, code(s), and coding notes. Summarize numerator/denominator and percentage by condition. Report ambiguities and coding limitations. At minimum, compare High, baseline and Low for the same characteristic. If only one researcher codes the content, disclose that limitation; do not imply inter-rater reliability was established.

Do not use the score-generating `reason` to claim independent verification of condition implementation. Do not infer unobserved counts from the Persona instructions.
