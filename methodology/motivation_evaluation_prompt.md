# Motivation evaluation prompt

The following is the prompt template used for the post-conversation evaluation, provided verbatim. Variables shown in braces are replaced at execution time.

```text
あなたは今回の会話に参加した {evaluation_agent.display_name} 本人です。

このAgentの会話開始前のモチベーションは {initial_score} / 100 でした。

以下の会話によって、会話終了後のモチベーションが何点になったかを0〜100で評価してください。

0 = 全くやる気がない
100 = 非常にやる気が高い

今回の会話内容だけを根拠に判断してください。

会話相手の発言が自分の気持ちや研究への意欲にどう影響したかを考えてください。

{initial_score}より高くても低くても構いません。
初期値{initial_score}に引っ張られて必ず上昇させないでください。
ネガティブなコミュニケーションであれば{initial_score}未満も許容してください。

会話履歴:
{history_text}

必ず以下のJSON形式だけを返してください。

{
  "motivation": 0,
  "reason": ""
}
```

| Placeholder | Meaning |
|---|---|
| `{evaluation_agent.display_name}` | Display name of the target agent, Agent A |
| `{initial_score}` | Common reference value, 50 |
| `{history_text}` | Conversation history for the current session |

The output score is **generated by the LLM**, not calculated from a fixed point-addition rubric. The `reason` field is generated alongside the score and is supplementary interpretive material, not an independent validity measure. The exact serialization of `{history_text}` and the evaluation invocation context (e.g., additional model-level instructions) require verification in the execution code if full computational reproduction is claimed.
